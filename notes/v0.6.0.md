**Windows:** run `DrelvaScope-Setup.exe`. **macOS 10.15 or later:** open `DrelvaScope.dmg` and run the installer inside (not signed by Apple: if macOS blocks it, System Settings → Privacy & Security → **Open Anyway**). Manual: `DrelvaScope_v0.6_Manual.pdf`.

Includes everything planned for v0.5. Sessions and presets from earlier versions open as they were.

### New
- **SHADER layer**: your own GLSL. **ISF 2.0** files (Resolume / VDMX format) load as-is, with their inputs as parameters and modulation targets; ISF filters work as effects on the layers below; Shadertoy `mainImage()` and plain GLSL too. Built-in **CODE** editor with live reload. Four examples: PLASMA BASS, HEX PULSE, SPECTRUM RINGS, RGB SLICE.
- **MESH layer**: 3D models (**.obj, .gltf, .glb**) or built-in shapes (icosphere, cube, torus, torus knot, terrain). Tempo-locked spin, DISPLACE by the spectrum and the kick, SOLID / WIRE / BOTH, three shading styles.
- **Export video** (right-click the stage): render a track to **MP4** or a **PNG sequence**, 720p to 4K, square or vertical, 24–60 fps, frame-perfect.
  - **RECORD FROM DAW**: no bounce needed. Arm it, press play (or export audio) in the DAW, and BPM + start beat come from the DAW.
- **SHARE**: send the picture to Resolume, OBS, TouchDesigner, MadMapper... GPU to GPU through **Spout** (Windows) / **Syphon** (macOS).
- **RANDOM → From text**: describe a look ("dark industrial tunnel, punchy kick, magma") and get a patch. Offline built-in words (English and Portuguese), or a language model of your choice with your own API key: Claude, OpenAI, Gemini, OpenRouter, Mistral, Groq, DeepSeek, xAI, Ollama / LM Studio.
- New sources:
  - **SIDECHAIN**: SC PEAK / SC RMS / SC HIT follow only the track you send to the sidechain input.
  - **SONG**: TENSION, DENSITY, DROP, BREAKDOWN, from the structure of the track.
  - **INSTRUMENTS** (experimental): INST DRUMS / BASS / VOX / SYNTH, how likely each is to be playing, from a small neural network inside the plugin.
- **MONOCHROME** on MASTER / POST FX.
- **RESET MAPS**: remove all modulation, one layer's, or the learned MIDI CCs at once (undoable).
- **AU** for Logic / GarageBand. Mono tracks accepted.
- Three new factory patches: SHADER PLASMA, SLICE TUNNEL, MESH ORB (19 in total).

### Changed
