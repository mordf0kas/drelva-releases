# Scope v1.0

Updated October 6, 2026. The version remains v1.0.

## Improvements
- Previous/next preset arrows now include saved user patches and continue from the selected user patch during editing.
- The mouse wheel over the preset controls browses patches; missing or unreadable files are skipped.
- Fixed audio-enabled MP4 export stalls on macOS by feeding audio and video independently, with cancellation and bounded waits.
- Added direct Export access from the top toolbar and clearer toolbar controls.
- Added a saved Mouse / Touchpad mode. Mouse retains wheel adjustment; Touchpad scrolls panels, with Ctrl/Cmd+scroll for intentional parameter changes.
- M1-M8 show mapped destination values. Macros with multiple mappings offer a destination list; host automation remains normalized for compatibility.
- Updated the illustrated PDF manual with export, input-mode and macro-readout instructions.

## Downloads
- Windows: VST3 installer (`DrelvaScope-Setup.exe`).
- macOS: universal Intel / Apple Silicon VST3 and AU installer (`Scope-v1.0-macOS.pkg`), also available inside `DrelvaScope.dmg`.
- Manual: `Scope-v1-Manual.pdf`.
- No standalone application is included. Existing installed standalone copies are not removed.

Native macOS tests passed on Intel and Apple Silicon, including MP4 audio combinations, cancellation and full 720p/1080p renders. Windows build, session tests, PNG and MP4 regressions passed. The preset-navigation regression suite passes on Windows. Automated tests do not cover every DAW or macOS version.

The macOS package uses ad-hoc bundle signatures, not Apple notarization. macOS may require approval in Privacy & Security when installing.
