# Drelva Scope v0.4.0

**Webcam input**
- Any IMAGE slot can show the live webcam; **+ LAYER → CAMERA** adds a mirrored, full-stage camera layer.
- New modulation sources from the camera: **MOTION**, **MOVE X**, **MOVE Y**, **CAM LUMA** — movement in
  front of the camera drives the visuals like a band does.
- Windows and macOS. On macOS use the standalone app for the camera if your DAW does not ask for camera
  access (the plugin tells you instead of crashing the DAW).
- TEST PATTERN camera to build camera patches without a webcam.

**Random routing**
- RANDOM in the top bar: a fresh routing for everything, the selected layer, one band / source, depths
  only, or a small mutation — subtle / medium / wild, and which kinds of sources it may use.
- RANDOM ROUTE per band / source (inspector), RANDOM MOD per layer (parameter panel).

**Undo / redo** — Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z.

**SOURCES panel rebuilt** — each band has its own lane under the spectrum (no more overlapping boxes),
the selected band is lit on the spectrum with a draggable threshold line, the other sources are grouped
(AUDIO / CLOCK / LFO / CAMERA) and every chip shows how many parameters it drives; hover a chip to see
them. BAND KIT presets, + BAND.

**15 new factory patches** — PHOSPHOR XY, MONO TUNNEL, MAGMA SPIRAL, ICE MIRROR, SOLAR RADIAL, HEX RAVE,
CONTOUR FIELD, KALEIDO EMBED, ORB PULSE, STRIPE MOIRE, ART BANK, ART DISSOLVE, RAW CRT, ICE WATERFALL,
CAMERA KALEIDO.

Sessions and presets from v0.3 open unchanged. v0.3.0 stays available below.

Installers: `DrelvaScope-Setup.exe` (Windows: Standalone + VST3), `DrelvaScope.dmg` (macOS: .pkg with
Standalone + VST3). Unsigned — see the README for the first-run steps.
