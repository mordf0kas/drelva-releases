# Drelva Scope — downloads

Audio-reactive visual engine plugin (VST3/Standalone) by DRELVA: draw frequency bands, route them (and
your webcam) to a stack of visual layers (phosphor scope, spectrum, tunnel, spiral, image / GIF frame
bank, camera, feedback).

This repo hosts only the installer downloads — no source code (that lives in a private repo).

See the [Releases](../../releases) tab for the Windows `.exe` and macOS `.dmg` installers.

| Version | What's in it |
|---|---|
| **v0.4.0** | webcam input (camera layer + MOTION sources), random routing (all / per band / per layer), undo / redo, rebuilt SOURCES panel (one lane per band), 15 new factory patches — [notes](notes/v0.4.0.md) |
| v0.3.0 | layered visual engine, drawn bands, mod matrix, frame bank (GIF / PNG sequences), 12 factory patches |

Older versions stay available on the Releases page: install the one you want (each installer replaces
the plugin in the system VST3 folder).

Both installers are unsigned/not notarised: on first run, right-click → Open (Mac) or click
"More info" → "Run anyway" (Windows SmartScreen) to bypass the unknown-publisher warning.
